## 🌟 About This Project

**Smart Expense Tracker** is a Python-based application that helps users manage their daily expenses efficiently.

### ✨ Features

* ➕ Add new expenses.
* 💾 Save expenses into CSV.
* 📊 View expense summary.
* 📂 Filter expenses by category and date.
* 📄 Generate detailed expense report.
* 📈 Visualize expenses with graphs.
